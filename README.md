# NOVA - Voice Assistant (v3)

A personal AI-powered voice assistant built with Python, capable of
responding to voice commands and performing tasks hands-free.

## Features
- 🎙️ Voice recognition and response
- 🔊 Text-to-speech output
- 🤖 Smart conversational replies
- 📅 

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3 / gTTS

## Setup Instructions

### Prerequisites
- Python 3.x installed

### Installation
1. Clone the repository
```bash
   git clone https://github.com/LittlePython12/NOVA-v3.git
   cd NOVA-v3
```

2. Install dependencies
```bash
   pip install -r requirements.txt
```

3. Run the assistant
```bash
   python main.py
```
